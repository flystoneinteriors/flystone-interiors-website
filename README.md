# Flystone Interiors — Beautiful V3

This version focuses on a premium, photo-first interior-design experience:
- Full-screen visual hero
- Luxury navy / gold / cream brand palette
- Large signature project feature section
- Masonry gallery with filters
- Click-to-enlarge lightbox
- Floating call + WhatsApp contact buttons
- High-contrast enquiry section
- Existing Azure API/admin architecture retained
- Deployment workflow uses `skip_app_build: true`

All gallery imagery in this package originates from the Flystone reference/project images supplied for this build. Add more original project photos through the admin/storage flow for the final production gallery.

Azure Static Web Apps:
- Build preset: Custom
- App location: /
- API location: /api
- Output location: blank
- Deployment token authentication
